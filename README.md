# Rentora

বাড়িওয়ালাদের জন্য ভাড়া ব্যবস্থাপনার সফটওয়্যার (Rental Management SaaS)।
**Powered by [SIDDIQIYA Technology](https://hsdmj.com)** · ঠিকানা: https://rentora.hsdmj.com

## কী আছে

| অংশ | কাজ |
|---|---|
| `index.html` | পরিচিতি পাতা: সুবিধা, দাম (ডাটাবেস থেকে), প্রশ্ন-উত্তর, ফ্রি ট্রায়াল |
| `login.html` | লগইন, সাইন আপ, পাসওয়ার্ড রিসেট (বাড়িওয়ালা ও ভাড়াটিয়া আলাদা) |
| `app.html` | বাড়িওয়ালার ড্যাশবোর্ড: ভাড়ার খাতা, সম্পত্তি › ভবন › ফ্ল্যাট/দোকান › রুম, ভাড়াটিয়া ও চুক্তি, মাসিক ইনভয়েস, টাকা জমা ও রসিদ, ইউটিলিটি বিল, আয়-ব্যয়, SMS/WhatsApp, সাবস্ক্রিপশন, টিম, ব্যাকআপ |
| `tenant.html` | ভাড়াটিয়া পোর্টাল: বকেয়া, ইনভয়েস, রসিদ |
| `admin.html` | Super Admin: সব গ্রাহক, সাবস্ক্রিপশন, পেমেন্ট যাচাই, প্যাকেজ ও দাম, প্ল্যাটফর্ম সেটিংস |
| `supabase/migrations/` | ডাটাবেস, Row Level Security, ব্যবসায়িক ফাংশন |
| `supabase/tests/` | ১০৯টি নিরাপত্তা ও হিসাবের টেস্ট |

## প্রযুক্তি

- ফ্রন্টএন্ড: সাধারণ HTML/CSS/JavaScript (build step নেই), GitHub Pages-এ হোস্ট
- ব্যাকএন্ড: Supabase (PostgreSQL, Auth), প্রতিটি টেবিলে RLS
- ভূমিকা: Super Admin, মালিক, ম্যানেজার, হিসাবরক্ষক, ভাড়াটিয়া
- টাকা সংক্রান্ত সব কাজ (ইনভয়েস, জমা, সাবস্ক্রিপশন অনুমোদন) সার্ভারে যাচাই হয়; ব্রাউজার থেকে অঙ্ক বা অবস্থা বদলানো যায় না
- প্রতিটি পরিবর্তনের অডিট লগ, রাতের এনক্রিপ্টেড ব্যাকআপ

`assets/js/config.js` খালি থাকলে অ্যাপ ডেমো মোডে নমুনা তথ্য দিয়ে চলে।
